# 伝わる化チェッカー Lite v0.1

文章の長さ・改行・登録済み表現をルールで点検する無料の試作版です。`index.html` をブラウザで開くだけで動作し、ビルドやAPIキーは不要です。

入力文章は外部送信・保存しません。スコアは独自の目安で、意味理解・事実確認・AI執筆判定は行いません。入力上限は20,000文字です。

整形は改行と空白だけを変更します。単語は削除せず、段落・箇条書き・見出し・コードを保護します。文章の用途に合うか、結果は元の文章と見比べてください。

## GitHub Pages

このフォルダの `index.html` と `.nojekyll` を公開用リポジトリのルートに配置します。Settings → Pages → Deploy from a branch で `main` / `/(root)` を指定してください。

公開後、実際に発行されたURLで動作を確認します。note原稿は別ファイルのため、このリポジトリへのアップロードは不要です。

## 利用計測

現時点で利用回数の自動集計はありません。感想は紹介元のnote記事のコメント欄で受ける運用です。[紹介記事・フィードバック窓口](https://note.com/kkkrock271310/n/n1382792c4b20)へのリンクを公開ページに設置しています。
